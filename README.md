**🧠 Futurense US Pathway Program Project**
Welcome to the official repository of the Futurense US Pathway Program project. This end-to-end data analysis and machine learning initiative focuses on deriving meaningful insights, optimizing program efficiency, and building predictive models using real-world student and marketing data. The project combines statistical analysis, data visualization, and actionable recommendations to address core business challenges.

🎯 Project Objectives
📈 Audience Engagement: Analyze marketing channels (e.g., Facebook, LinkedIn, webinars) to measure and improve reach.

👨‍💼 Agent & Counselor Analysis: Identify top and low-performing agents using KPIs; recommend training and support actions.

⏱ Lead-to-Payment Optimization: Reduce time gaps from lead generation to payment for better user experience and process efficiency.

🤖 Predictive Modeling: Build ML models to forecast lead conversions and support strategic decisions.

🔍 Key Insights
Top Channels: Facebook, inbound phone calls, and referrals show the highest conversion efficiency.

Improvement Areas: LinkedIn and Zoom webinars need performance-driven re-engagement strategies.

Agent Performance: A small group of high-performing agents drives significant success; training required for underperformers.

Process Bottlenecks: Delays in lead-to-token and lead-to-payment transitions can be optimized for better turnaround times.

🛠 Tools & Technologies Used
Languages: Python

Libraries: Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

Visualization: Power BI

Statistical Techniques: Chi-square test, missing data analysis (MCAR, MAR, MNAR), correlation

Project Tools: Jupyter Notebooks, GitHub
